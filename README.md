## Overview
This project is a basic webpage developed to practice HTML structure and CSS styling. It demonstrates the use of common HTML elements and external stylesheets to control the appearance of a webpage.

## Features
- Structured webpage content using HTML elements, including headings, paragraphs, and ordered lists.
- External CSS stylesheet for webpage styling.
- Hover effects that dynamically change paragraph text color and font size.
- Embedded animated GIF using an externally hosted image.

## Languages Used
- HTML
- CSS

## Project Structure
- `web.html` — Contains the webpage structure and content.
- `style.css` — Defines the webpage's visual styling and hover effects.

## Learning Objectives
- Practice structuring content with HTML.
- Apply CSS rules to HTML elements.
- Understand external stylesheets and CSS hover selectors.
- Embed external images into a webpage.

## Project Status
Completed as a foundational HTML and CSS practice project.
